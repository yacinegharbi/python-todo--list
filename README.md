# Python Todo List

A simple CLI todo list application written in Python.

## Features

- Add tasks
- Modify tasks
- Remove tasks
- Show all tasks
- Exit cleanly

## Usage

1. Run the app:

```bash
python todo-list.py
```

2. Choose one of the menu options:

- `1` to add a task
- `2` to modify a task
- `3` to remove a task
- `4` to show all tasks
- `5` to exit

3. Follow the prompts to manage your todo list.

## Notes

- The app stores tasks in `todo-list.txt`.
- A `.gitignore` file is included to avoid committing local environment files and the task file.
